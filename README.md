# Morg Elements

Estudo sobre os quatro temperamentos (melancólico, sanguíneo, fleumático e colérico), organizados num círculo de elementos e subtipos.

> Nada aqui deve ser levado como verdade. É o estudo de uma tradição filosófica e caracterológica, não ciência.

- `index.html`: página com o círculo animado, os quatro temperamentos, os subtipos e as referências.
- `docs/pesquisa.md`: anotações da pesquisa e referências (só fontes primárias, cada uma com seu estado de verificação).
